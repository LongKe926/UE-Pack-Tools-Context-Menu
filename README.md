# 中文
将 [**Unrealpak**](https://github.com/xamarth/unrealpak)、[**repak**](https://github.com/trumank/repak)、[**retoc**](https://github.com/trumank/retoc) 的拆封包功能添加至Windows的右键菜单中，可以随时随地大小封

将此文件夹放置到**纯英文目录**，运行 ``Add Context-Menu.bat`` 添加到右键菜单

如果你移动了该文件夹，则需要重新添加

# English
Add the pack and unpack function of [**Unrealpak**](https://github.com/xamarth/unrealpak)、[**repak**](https://github.com/trumank/repak)、[**retoc**](https://github.com/trumank/retoc) to the Windows right-click context menu, so you can pack and unpack anytime, anywhere.

run ``Add Context-Menu.bat``

If you move this folder, you will need to add it again.
